Replaces v0.1.0, whose package could not complete its first install.

## What was wrong with v0.1.0

The package installed, the launcher ran, and `labeloxav install` got as far as building the container
images before failing with `License file does not exist: LICENSE`. The same commit that added the
Apache licence pointed the package metadata at that file, and the Dockerfile copies only
`pyproject.toml` and `README.md` before its first dependency install, so the build backend could not
find it. This affected any Docker build of that commit, not only the package.

It was found by installing the published `.deb` on a clean Ubuntu 24.04 with its own Docker daemon and
running the install end to end, which the v0.1.0 checks had not done. That end-to-end install is now
what stands behind a release.

## What is in this release

Everything in v0.1.0, with the Dockerfile fixed and a test that keeps the package metadata and the
Dockerfile's early copy step in agreement. The notes for v0.1.0 describe the product, the package, and
the honest state of the corpus, and they still apply.

```
sudo apt install ./labeloxav_0.1.1_all.deb
sudo labeloxav install
labeloxav url
```
